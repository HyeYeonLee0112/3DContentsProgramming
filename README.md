# 3D콘텐츠프로그래밍 · 3D Contents Programming

서울여대 2026-2학기 · 전공선택 · 3학점 · 화 3–4교시

Unity로 3D 인터랙티브 콘텐츠를 만드는 과목. 강의 예제를 그대로 따라하는 대신 **배운 기능을 다른 규칙으로 옮겨** 매주 30–90초 플레이 가능한 결과물을 남긴다.

## 이 레포에 남기는 것

- 주차별 마이크로 프로젝트 / 기술 데모 (기본 도형 + 임시 에셋, 씬 1개, 핵심 기능 1개)
- 각 결과물: `배운 기능 → 바꾼 규칙 → 확인한 결과` 회고
- 9–11주 스폰·UI·게임 매니저 통합 → 12–15주 최종 미니게임
- 필기시험 대비 회상 노트는 `exam/`

## 구성(예정)

```
weekNN-topic/  # 주차별 Unity 프로젝트 또는 씬
builds/        # 빌드·영상 링크
exam/          # 필기 회상 노트
docs/          # 강의계획서
```
