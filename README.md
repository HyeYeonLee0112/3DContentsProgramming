# 3D콘텐츠프로그래밍 · 3D Contents Programming

> Unity로 입력·물리·AI·애니메이션·게임 매니저를 주차별 플레이 가능 결과물로 구현.

## 커리큘럼 & 구현 현황

**상태** ⬜ 예정 · 🟨 진행 · ✅ 완료
**깊이** `📖 개념` · `🎮 예제 재현` · `🔧 규칙 변형 응용` · `🧩 기능 통합` · `✨ 조작감·피드백 개선`

| 주제 | 상태 | 깊이 | 증거 |
|---|:--:|:--:|---|
| 입력 · 이동 · 회전 · 점프 | ⬜ | | `week02-movement/` |
| 프리팹 · 발사체 | ⬜ | | `week03-projectile/` |
| 특수효과 · NavMesh 길찾기 | ⬜ | | `week04-navmesh/` |
| AI (순찰·추적·공격) · 코루틴 | ⬜ | | `week05-stealth/` |

필기시험 대비 회상 노트 → `exam/`

## 다룬 범위 / 다루지 않은 범위

- **다룸**: FPS/TPS 미니게임에 필요한 입력·물리·AI·애니메이션·UI·게임 루프. 매주 강의 기능을 다른 규칙으로 옮겨 30–90초 플레이 결과물.
- **안 다룸**: 고품질 3D 아트·대규모 맵, 네트워크 멀티플레이(Photon 등), 저장 시스템, 셰이더.

## 실행

각 `weekNN-*/` 는 Unity 프로젝트 또는 씬. 빌드·플레이 영상 링크는 `builds/`. 에셋은 Git LFS.
