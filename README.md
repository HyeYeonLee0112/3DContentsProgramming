# BLACKOUT

> **전력을 되살려 길을 열고, 필요할 때 다시 회수해 전황을 바꾸는 3인칭 액션 TPS**

`BLACKOUT`은 정전된 도시 기반 시설을 배경으로 하는 싱글플레이 3D 액션 프로젝트입니다. 플레이어는 정비사가 되어 오작동한 관제 시스템을 멈추기 위해 통신탑으로 향합니다. 적 로봇에게서 회수한 전력은 단순한 탄약이 아니라, 조명·보안문·수송 설비를 작동시키고 다시 꺼뜨릴 수 있는 게임 세계의 자원입니다.

> 현재 상태: **프리프로덕션 / 구현 및 무료 에셋 도입 검증 전**  
> 엔진: **Unity · URP · PC · 싱글플레이**

## 프로젝트 한눈에 보기

| 구분 | 내용 |
|---|---|
| 장르 | 3인칭 슈팅 액션(TPS) · 환경 상호작용 |
| 플레이 시간 목표 | 첫 플레이 약 35분 |
| 핵심 무기 | 펄스총 1종 — 기본 사격, 충전 사격, 전력 흡수·주입 |
| 핵심 선택 | 전력을 공격에 쓸지, 공간을 바꾸는 시설에 쓸지 선택 |
| 적 구성 | 추적 로봇, 포탑, 감시 드론, 방패 유닛, 최종 보스 |
| 아트 방향 | 현실적인 도시 기반 시설·산업 장비·비완구풍 로봇 |

## 플레이어 경험

전력을 시설에 넣으면 어두운 통로가 밝아지거나, 닫힌 보안문과 수송 설비가 작동합니다. 하지만 전력은 제한적이므로, 필요해진 순간에는 시설에서 다시 전력을 회수해 충전 사격에 쓸 수 있습니다.

즉, 같은 공간에서도 다음과 같은 선택이 생깁니다.

- 조명을 켜서 적의 위치를 먼저 확인한다.
- 문이나 승강기를 작동시켜 더 안전한 길을 만든다.
- 시설의 전력을 회수하고, 충전 사격으로 위험한 적을 빠르게 처리한다.
- 전력이 없어도 기본 사격과 우회 경로로 게임을 끝까지 진행한다.

## 핵심 게임 루프

```text
관찰
  → 적 일부 처치
  → 전력 회수
  → 시설 가동 또는 충전 사격 선택
  → 달라진 공간을 이용해 이동·전투
  → 필요 시 전력 회수
  → 체크포인트
```

## 구현 범위

| 시스템 | 구현 내용 | 플레이어에게 보이는 결과 |
|---|---|---|
| 캐릭터 조작 | 이동, 점프, 카메라, 조준, 상호작용 | 3인칭 시점에서 탐색·전투·시설 조작을 자연스럽게 연결한다. |
| 펄스총 | 기본 사격, 충전 사격, 전력 흡수, 전력 주입 | 하나의 무기로 전투와 환경 조작을 함께 수행한다. |
| 전력 시스템 | 최대 3칸 저장, 1칸 단위 이전, 유한 충전소 | 제한된 자원을 공격과 이동 중 어디에 쓸지 판단한다. |
| 가동 시설 | 조명, 보안문, 고정 경로 승강기 | 전력의 주입·회수에 따라 시야, 안전, 이동 경로가 바뀐다. |
| 적 행동 | 순찰, 감지, 조사, 공격, 사망, 유한 경보 | 같은 전력 선택도 적의 위치와 경계 상태에 따라 다르게 작동한다. |
| 보스전 | 3단계 패턴, 유한 보조 적, 안전한 승리 전환 | 앞서 배운 이동·사격·전력 판단을 하나의 전투에서 응용한다. |
| 체크포인트 | 안전 지점 저장, 사망 복원, 진행 상태 유지 | 실패 후에도 전력·시설·적·목표가 납득 가능한 상태로 되돌아간다. |
| 피드백 | HUD, 상호작용 안내, 실패 이유, 소리·형태 신호 | 전력 상태와 위험을 색상 하나에만 의존하지 않고 전달한다. |

## 게임 진행

| 구역 | 플레이 목적 | 전력이 만드는 변화 |
|---|---|---|
| 화물역 | 조작과 전력 회수·주입 학습 | 조명 또는 보안문으로 첫 안전 경로를 만든다. |
| 침수 시장 | 수동 단말기로 통로를 해제 | 조명·셔터를 이용해 시야와 적 접근을 조절한다. |
| 고가 수송로 | 수직 전투와 이동 경로 선택 | 수송 설비와 우회 계단 사이에서 위험을 판단한다. |
| 중앙 관제탑 하부 | 보스 접근을 막는 방어 장치 해제 | 문·조명으로 적을 분리하고 약점을 확인한다. |
| 통신탑 옥상 | 관제탑 경비 로봇 격파 | 전력을 시설과 충전 사격 중 어디에 쓸지 최종 판단한다. |

## 조작 계획

| 입력 | 동작 |
|---|---|
| `WASD` / `Space` / `Shift` | 이동 / 점프 / 달리기 |
| 마우스 / 우클릭 | 카메라 / 조준 |
| 좌클릭 | 기본 사격 |
| `R` 길게 누르기 | 충전 사격 |
| `E` | 전력 흡수 |
| `Q` | 시설에 전력 주입 |
| `F` | 단말기·키·승강기 상호작용 |

## 포트폴리오에서 보여줄 구현 포인트

- **상태가 바뀌는 공간:** 조명·문·승강기가 단순 장식이 아니라 전력 상태에 따라 실제 길과 전투 조건을 바꾼다.
- **일관된 자원 규칙:** 적 사체, 시설, 충전소 사이에서 전력이 복제되거나 사라지지 않도록 관리한다.
- **전투와 환경의 결합:** 같은 펄스총이 공격 도구이자 세계 상호작용 도구로 기능한다.
- **실패 후 신뢰 가능한 복원:** 체크포인트 이후에도 적·시설·충전소·목표가 저장 시점과 일치한다.
- **완결된 플레이 흐름:** 시작부터 보스전·엔딩까지 에디터 밖 실행 파일로 시연한다.

## 제작 원칙

- 무기는 펄스총 하나만 사용한다.
- 살아 있는 적이나 보스에게서 전력을 빼앗지 않는다.
- 전력 0 상태에서도 기본 사격과 우회 경로로 엔딩까지 진행할 수 있어야 한다.
- 새 총, 스킬트리, 제작, 멀티플레이, 무한 웨이브, 추가 보스는 범위에 넣지 않는다.
- 유료 에셋은 사용하지 않으며, 최종 결과는 비완구풍의 통일된 산업 SF 분위기를 유지한다.
- 직접 모델링·텍스처 제작·수작업 공격 애니메이션이 필수인 해결책은 채택하지 않는다.

## 개발 단계

1. **에셋 도입 검증** — 주인공, 펄스총, 추적 로봇, 보스를 한 장면에서 검수한다.
2. **첫 플레이 가능 구역** — 화물역에서 이동·사격·전력·시설·적·체크포인트를 끝까지 연결한다.
3. **전력 선택 검증** — 전력을 사용했을 때 안전·시간·공격 기회가 실제로 달라지는지 플레이 테스트한다.
4. **저장 복원 검증** — 반복 사망·복원에서도 전력과 세계 상태가 어긋나지 않는지 확인한다.
5. **콘텐츠 확장 및 마감** — 적 역할, 구역, 보스, 엔딩을 추가하고 실행 파일 전체를 검수한다.

## 개발 상태와 주의 사항

이 README는 포트폴리오용 소개 초안입니다. 적 4종과 보스의 실제 모델·공격 동작·라이선스, 움직이는 시설의 동작, 전체 저장 복원은 아직 구현 완료를 주장하지 않습니다. 각 항목은 Unity 안에서 검증된 뒤 시연 영상·스크린샷·빌드 정보로 교체합니다.
