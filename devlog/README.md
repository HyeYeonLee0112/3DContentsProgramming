# BLACKOUT 개발 기록

BLACKOUT은 정전된 화물 시설에서 전력을 회수하고 다시 배치해 길, 조명, 장치와 위험을 바꾸는 3인칭 슈팅 게임이다.

이 공간은 프로젝트를 처음 보는 사람이 게임의 방향, 실제 개발 과정, 설계 판단, 문제 해결과 성능 검증을 따라갈 수 있도록 정리한 공개 개발 기록이다.

## 읽는 순서

1. [프로젝트 소개](project-overview.md)에서 게임의 목표와 핵심 규칙을 확인한다.
2. [개발 일지](weekly/README.md)에서 주차별 구현 과정을 본다.
3. [트러블슈팅](troubleshooting/README.md)과 [성능 기록](performance/README.md)에서 문제를 어떻게 확인하고 개선했는지 본다.
4. [설계 결정](decisions/README.md)에서 주요 구조를 선택한 이유와 대안을 확인한다.

현재는 W02를 준비하는 단계다. 아직 구현하거나 검증하지 않은 기능을 완료된 것처럼 기록하지 않는다.
