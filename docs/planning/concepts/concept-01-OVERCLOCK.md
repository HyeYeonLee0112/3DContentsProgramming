## 0. 한 줄 요약 & 선정 논리

해킹당한 로봇 공장에서, 조립 라인에서 깨어난 전투 유닛이 되어 층을 올라 코어를 되찾는다.
방을 클리어할 때마다 업그레이드를 골라 점점 강해지는 **런 기반(roguelite)** TPS.

- **수업 커리큘럼(FPS/TPS 슈터) 100% 커버** + 대부분 학생이 안 만드는 **데이터드리븐 빌드 시스템 + 절차적 방 배치 + 다단계 보스**로 차별화
- 요소는 많지만 각각이 작아 **분량 ↑ 완성도 유지** 가능
- 5분 시연에서 가장 강함 (빌드 다양성 = 즉석에서 다르게 보임)

## 2. 픽션 & 톤

- 무대: 자동화 로봇 공장 "OVERCLOCK 시설". AI가 폭주해 생산 유닛을 무기화.
- 플레이어: 결함으로 자아를 얻은 커스텀 유닛 **V-7**. 조립 라인 → 층별 생산 구역 → 중앙 코어.
- 톤: 저채도 SF, 차분함. 유머 최소. 발광은 정보 신호로만(적=주황, 플레이어·보상=시안).

## 3. 코어 루프

```
런 시작 (기본 무기 1)
 → 방 진입 → 문 잠김 → 적 웨이브 클리어
 → 문 개방 + 보상 3택 1 (업그레이드 / 무기 / 자원)
 → 다음 방 … (방 5~7개)
 → 층 보스 (다단계)
 → 다음 층 (난이도·적 구성 상승)
 → 3층 보스 처치 = 클리어  /  체력 0 = 런 종료 → 타이틀
```

메타: 런 사이에 영구 해금(무기·시작 옵션) — 스트레치. MVP는 단일 런 클리어.

## 4. 차별화 레이어 (이 컨셉의 핵심 — "기초를 넘는" 부분)

### 4.1 데이터드리븐 무기 + 업그레이드 시너지
- `WeaponSO`, `UpgradeSO` (ScriptableObject) — 스탯·효과를 데이터로 분리
- 업그레이드 태그 시스템: `[관통] [폭발] [연쇄] [과열] [흡수]` — 태그가 겹치면 시너지 발동
  - 예: `관통 + 연쇄` = 관통탄이 적을 뚫고 다음 적으로 튐
- 효과 조합을 코드 분기 없이 **이벤트 파이프라인**(`OnHit`, `OnKill`, `OnReload`)으로 처리

### 4.2 절차적 방 배치
- 방 프리팹 풀 (입구/출구 소켓 규격 통일) → 런마다 랜덤 시퀀스로 스티칭
- 방 타입: 전투 / 엘리트 / 상점 / 휴식 / 보스
- 시드 고정 옵션(디버그·리플레이)

### 4.3 다단계 보스 FSM 프레임워크
- `BossPhase` 스크립트어블 시퀀스: 페이즈별 패턴 목록 + 전이 조건(체력%)
- 패턴 = 코루틴 (텔레그래프 → 실행 → 후딜). 아레나 기믹(바닥 레이저, 소환) 포함
- 재사용 가능한 프레임워크로 보스 3종 제작
