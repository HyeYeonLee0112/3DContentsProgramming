## 0. 프로젝트 의의 (읽고 시작할 것)

이 프로젝트의 목적은 **재미있는 게임**이나 **참신한 기획**이 아니다.
목적은 **3D 게임 프로그래밍의 기초를 빠짐없이 직접 구현해 보는 것**, 그리고 강의 커리큘럼에서
다룬 기능을 최대한 코드로 녹여 넣고 그 위에서 한 단계 더 심화 학습·구현하는 것이다.

Grid Defenders(3D 타워 디펜스)를 고른 이유:

- **커버 범위가 가장 넓다** — 레이캐스팅, AI 경로탐색, 대량 오브젝트 관리, VFX, 절차적 생성,
  LOD/컬링, 프로파일링 최적화를 하나의 씬 안에서 전부 겪는다.
- **범위 조절이 쉽다** — 타워/적 종류 수로 난이도와 분량을 조절 가능.
- **정량 비교가 자연스럽다** — "직접 구현 A\* vs NavMesh", "풀링 전/후 프레임타임" 같은
  측정 가능한 산출물이 그대로 보고서가 된다.

평가 대상은 **게임의 완성도**가 아니라 **각 3D 기초 시스템의 구현 품질과 이해도**다.

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 제목 | Grid Defenders |
| 장르 | 3D 타워 디펜스 (그리드 배치, 웨이브 방어) |
| 시점 | 쿼터뷰 / 자유 회전 RTS 카메라 |
| 플랫폼 | PC (Windows), 마우스+키보드 |
| 플레이 시간 | 맵당 10~15분, 맵 2개 |
| 한 줄 소개 | 그리드에 타워를 지어 경로를 따라 몰려오는 적을 막는다. |

### 코어 루프

```
맵 진입 → 준비 시간(타워 배치) → 웨이브 시작 → 적 스폰·이동·전투
   → 웨이브 클리어(골드 획득) → 타워 추가/업그레이드 → 다음 웨이브
   → 10웨이브 생존 시 승리 / 라이프 0 시 패배
```

### 승패 조건

- **승리**: 마지막(10) 웨이브의 모든 적 처치
- **패배**: 경로 끝(코어)에 도달한 적 누적 20마리 → 라이프 0

## 3. 상세 기능 명세

### 3.1 그리드 & 배치 시스템

**데이터 구조**

- `GridManager` — `N × M` 셀, 각 셀 상태: `Empty / Tower / Path / Blocked / Buildable`
- 셀 크기 1 유닛, 그리드 원점 기준 `worldPos = origin + new Vector3(x, 0, z) * cellSize`
- 역변환: `cell = floor((worldPos - origin) / cellSize)`

**배치 흐름**

1. 타워 선택(UI) → 배치 모드 진입
2. 매 프레임 마우스 레이캐스트로 지면 교차점 계산 → 셀 스냅
3. 반투명 **고스트 프리뷰** 표시 (배치 가능=초록, 불가=빨강)
4. 배치 가능 조건:
   - 셀 상태가 `Buildable`
   - 골드 충분
   - **배치 후에도 스폰→코어 경로가 존재**(A\*로 검증, 없으면 불가)
5. 좌클릭 → 확정, 골드 차감, 셀 상태 `Tower`로, 적 경로 전체 재계산

**학습 포인트**: 레이캐스트 두 방식 비교

- `Physics.Raycast` (지면 콜라이더 필요)
- `Plane.Raycast` (수학적 평면, 콜라이더 불필요) → 문서에 장단점 정리

### 3.2 경로탐색 (프로젝트의 핵심)

**두 가지 구현을 모두 만들고 런타임 토글**

#### (A) 직접 구현 그리드 A\*

- `AStarPathfinder` — 4/8방향 이동, 대각선 코너 컷 방지
- 오픈리스트: **바이너리 힙**(직접 구현, 정글에서 학습한 자료구조 활용)
- 휴리스틱: 옥타일 거리(대각선 허용 시)
- **퍼널 알고리즘**으로 경로 스무딩 → 지그재그 제거
- 타워 배치/판매 시 경로 재계산, 결과 캐싱

#### (B) Unity NavMesh

- NavMesh 베이킹, `NavMeshObstacle`(carve)로 타워를 장애물 처리
- `NavMeshAgent`로 적 이동, `avoidancePriority`로 무리 회피

#### 비교 리포트 (산출물)

| 항목 | 커스텀 A\* | NavMesh |
|---|---|---|
| 경로 재계산 비용 (100마리, 타워 1개 추가) | 측정 | 측정 |
| 이동 자연스러움 | 스무딩 후 평가 | avoidance 평가 |
| 구현 난이도 / 제어 가능성 | 서술 | 서술 |

### 3.3 적 & 웨이브

**웨이브 데이터** — `WaveDataSO` (ScriptableObject)

```
Wave {
  entries: [ { enemyType, count, spawnInterval, startDelay } ]
}
```

**적 종류 3종**

| 타입 | 체력 | 속도 | 특징 | LOD |
|---|---|---|---|---|
| Grunt | 100 | 보통 | 기본 | 3단계 |
| Runner | 50 | 빠름 | 낮은 체력, 회피 우선 | 3단계 |
| Tank | 500 | 느림 | 스플래시에 강함 | 3단계 |

**스폰**

- `WaveSpawner` — 코루틴 스케줄러, 스폰 시 **풀에서 꺼냄**
- 난이도 스케일링: 웨이브 n의 적 체력 `= base * (1 + 0.15 * (n-1))`

**이동**

- 경로 좌표열을 따라 이동, 다음 웨이포인트로 `MoveTowards` + 회전 Slerp
- 코어 도달 시 라이프 감소, 풀로 반환

### 3.4 타워

**3종**

| 타워 | 공격 방식 | 특징 | 골드 |
|---|---|---|---|
| Arrow | 단일 타깃, **투사체(호밍)** | 균형, 기본 | 50 |
| Cannon | 단일 발사, **스플래시(범위 데미지)** | 뭉친 적에 강함, 느린 연사 | 100 |
| Frost | **히트스캔(레이)**, 슬로우 디버프 | 데미지 낮음, 속도 30% 감소 | 75 |

**공통 로직**

- 사거리 내 타깃 탐색(`OverlapSphere`), 타깃팅 정책: `First / Last / Closest / Strongest`
- 포탑 파트만 타깃 향해 회전(Y축 Slerp)
- 발사 시 쿨다운, 머즐 파티클 + 발사음 + 순간 포인트 라이트
- 업그레이드 3티어(데미지/사거리/연사), 판매(골드 70% 반환 + 경로 재계산)

**학습 포인트**: 투사체 vs 히트스캔

- 호밍 투사체: 콜라이더 + Rigidbody, 타깃 추적, 명중 판정
- 히트스캔: `Physics.Raycast` 즉시 명중, 라인 렌더러로 시각화
- 문서에 프레임 비용·체감 차이 비교

### 3.5 전투 & 이펙트

- 데미지 계산: `final = baseDamage * (1 - armor)` (Tank는 armor 보유)
- 피격 시 히트 파티클(풀), 체력바 갱신
- 사망 시 **디졸브 셰이더**(1초) + 사망 파티클 → 풀 반환, 골드 지급
- 스플래시: `OverlapSphere`로 범위 내 적 일괄 타격 + 폭발 VFX

### 3.6 카메라

`RTSCameraController`

- **팬**: WASD / 엣지 스크롤, 맵 경계 클램프
- **줌**: 마우스 휠, 높이+각도 동시 조절(min/max)
- **회전**: 마우스 중클릭 드래그 or Q/E, Y축 회전
- 모든 입력 `SmoothDamp`로 감쇠
- (심화) 지형 하이트맵 샘플링해 카메라 최소 높이 유지

### 3.7 절차적 생성

- **맵 생성**: 그리드에 스폰/코어 지정 후 랜덤 워크로 경로 생성, 주변은 `Buildable`
  - 시드 고정 가능(재현성 → 리플레이/디버그)
- **경로 리본 메시**: 경로 좌표열 → 폭 있는 3D 메시 런타임 생성
  - 정점/삼각형/UV 계산, `MeshCollider` 부착
  - 코너에서 노멀 보간

### 3.8 최적화 (심화 — 반드시 측정 로그 남길 것)

| 기법 | 적용 대상 | 측정 항목 |
|---|---|---|
| 오브젝트 풀링 | 적, 투사체, 파티클, 데미지 텍스트 | GC Alloc / frame, 스파이크 유무 |
| GPU 인스턴싱 | 동일 타입 적 메시 | Draw Call, SetPass Call |
| `MaterialPropertyBlock` | 적별 체력 색상 틴트 | 머티리얼 인스턴스 수 |
| LODGroup | 모든 적·타워 | 삼각형 수 (원거리) |
| Occlusion Culling | 정적 지형지물 | 렌더된 오브젝트 수 |
| Job System + Burst | 적 이동 벡터 계산 | main thread ms, 100/300/500 마리 |

각 항목 **적용 전/후 Unity Profiler 스크린샷 + 수치 표**를 보고서에 첨부.

### 3.9 UI

- **HUD**(스크린): 골드, 라이프, 웨이브 번호, 다음 웨이브 타이머, 배속 버튼, 타워 선택 바
- **월드 스페이스**: 적 체력바(카메라 향해 빌보드), 타워 사거리 원(데칼/셰이더)
- **배치 프리뷰**: 반투명 고스트 + 유효성 색상
- **타워 정보 팝업**: 클릭 시 스탯/업그레이드/판매

### 3.10 오디오

- BGM 1트랙, 웨이브 시작/승리/패배 스팅어
- 3D SFX: 타워 발사(타입별), 적 사망, 스플래시 폭발, 코어 피격
- `AudioSource` 풀링, spatial blend 1.0, 거리 롤오프 커브 설정
