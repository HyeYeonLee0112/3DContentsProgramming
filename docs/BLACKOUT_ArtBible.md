# BLACKOUT — 아트 바이블

> 목적: 여러 무료 에셋을 한 게임처럼 보이게 만드는 공통 규칙  
> 기술 기준: Unity 6000.3.22f1 · URP · 1920×1080 · Windows 60fps 목표  
> 시각 방향: **현실적인 도시 산업 시설 + 제한된 공공 설비 색상 + 전력 상태가 만드는 대비**

## 1. 시각 목표

![BLACKOUT 전력 상태 시각 목표](art/BLACKOUT_VisualTarget.png)

이 이미지는 2026-09-09에 생성한 **방향 확인용 콘셉트 이미지**다. 실제 게임 화면이나 설치된 에셋이 아니다. 구현 시 그대로 복제하는 것이 아니라 다음 세 가지만 맞춘다.

1. 같은 공간이 정전과 통전에서 즉시 다르게 읽힌다.
2. 주인공·일반 로봇·보스가 같은 산업 설비 세계에 속해 보인다.
3. 화면이 어두워도 이동 경로, 위험, 상호작용 지점은 보인다.

## 2. 절대 규칙

- 귀여운 비율, 큰 머리, 둥근 장난감 실루엣, 플라스틱 단색 재질을 사용하지 않는다.
- 네온을 분위기 장식으로 흩뿌리지 않는다. 빛은 전력·위험·목표 정보를 전달할 때만 쓴다.
- “우주선 내부”처럼 새하얗고 깨끗한 SF가 아니라, 실제로 오래 사용한 화물역을 만든다.
- 에셋마다 원래 색을 유지하지 않는다. 공통 재질·색·조명 규칙으로 묶는다.
- 어둡게 보이게 하는 것과 아무것도 안 보이게 하는 것을 혼동하지 않는다.

## 3. 한 문장 미술 방향

**젖은 콘크리트와 낡은 철골의 현실적인 화물역에서, 전력의 흐름만 차갑고 선명하게 보인다.**

## 4. 형태와 실루엣

주 환경은 ProductionCrate/RenderCrate의 [Modern Industrial Pack](https://www.productioncrate.com/objects/RenderCrate-Modern_Industrial_Pack)으로 고정한다. 이 팩의 직선형 플랫폼·비계·배관·덕트·케이블을 환경의 형태 기준으로 삼으며, 다른 환경 소품도 이보다 더 깨끗하거나 더 미래적으로 보이면 사용하지 않는다.

| 대상 | 기본 형태 | 멀리서 읽혀야 하는 특징 | 금지 |
|---|---|---|---|
| 환경 | 직각 철골, I빔, 컨테이너, 굵은 케이블 | 수평 이동로와 수직 승강기 | 둥근 우주선 복도, 과도한 장식 |
| 주인공 | 사람 비율, 작업복, 사각 배터리 가방 | 등에 세로 전력 표시 3칸 | 영웅 갑옷, 망토, 과장된 어깨 |
| 추적 로봇 | 앞쪽으로 기운 이족 보행 실루엣 | 낮은 머리와 긴 팔/센서 | 귀여운 눈, 작은 완구 비율 |
| 포탑 | 넓고 고정된 받침 + 분리된 회전축 | 얇은 조준선과 총열 방향 | 캐릭터 같은 얼굴 |
| 보스 | 넓은 어깨, 무거운 다리, 노출 가능한 등 코어 | 일반 적의 약 2배 높이 | 지나치게 거대해 실내 전투가 불가능한 크기 |
| 펄스총 | 산업용 공구와 소총의 중간 | 짧은 총열, 두꺼운 전력 챔버 | 현대 총기 그대로, 장난감 물총 |

## 5. 색상 체계

| 역할 | 색 | Hex | 사용 비율/장소 |
|---|---|---|---|
| 깊은 그림자 | 차콜 | `#171B1F` | 화면 기반 45~55% |
| 구조물 | 건메탈 | `#343B40` | 철골·기계 25~35% |
| 바닥·벽 | 더러운 콘크리트 | `#6B6E6A` | 큰 면 15~25% |
| 이동·주의 | 안전 황색 | `#D18A24` | 난간·바닥선·작업 설비 |
| 정상 전력 | 차가운 청록 | `#67D5E7` | 소켓·전력 경로·배터리 |
| 위험·적대 | 비상 적색 | `#C43A35` | 적 센서·경고·피격 |

청록과 적색은 동시에 넓게 쓰지 않는다. 청록은 플레이어가 다룰 수 있는 전력, 적색은 즉시 피해야 하는 위험이다. 색각 이상을 고려해 청록은 세로 막대/원형 소켓, 적색은 삼각 경고/점멸 패턴도 함께 사용한다.

## 6. 재질 규칙

- 큰 구조물: 거친 콘크리트, 도장 벗겨진 강철, 아연 도금 철판.
- 이동 설비: 기름때가 낀 금속, 고무 케이블, 안전 황색 도장.
- 주인공: 무광 섬유와 고무 70%, 금속 20%, 발광부 10% 이하.
- 적: 건메탈과 검은 도장 80%, 적색 센서 5% 이하. 전력 코어만 청록을 침범할 수 있다.
- 젖음은 바닥과 외부 유입부에만 강하게 사용한다. 모든 물체를 같은 광택으로 만들지 않는다.
- 표면 손상은 모서리·손잡이·바퀴 자국 등 접촉 이유가 있는 곳에 둔다.

에셋 원본 재질을 바로 사용하지 않고 `Assets/BLACKOUT/Art/Materials` 아래에 프로젝트용 Material을 만들어 색·Smoothness·Emission을 통제한다.

## 7. 조명과 전력 상태

| 상태 | 환경광 | 실용등 | 상호작용 표시 | 적 표시 |
|---|---|---|---|---|
| 정전 | 매우 낮은 청회색 | 드문 적색 비상등 | 꺼진 소켓의 약한 윤곽 | 적 센서만 적색 |
| 통전 | 중간 밝기 중성광 | 청백색 형광등 순차 점등 | 청록 선과 1~3칸 표시 | 활성화 순간 적색 점멸 |
| 전력 회수 | 0.25초 안에 단계적 소등 | 잔광 후 꺼짐 | 청록이 총으로 역류 | 비활성 장치의 센서 소등 |
| 보스 과열 | 배경은 유지 | 황색 회전 경광등 | 냉각기만 청록 | 코어는 흰색→적색 박동 |

플레이 경로에는 최소 명도 20~35%, 엄폐물에는 10~20%, 위험 예고에는 60% 이상의 대비를 확보한다. 완전한 검정은 화면 가장자리와 막힌 구역에만 사용한다.

## 8. 카메라와 화면 구성

- 16:9, 1920×1080 기준.
- 기본 TPS 카메라는 플레이어 어깨 위, 전투 중 캐릭터가 화면 높이의 약 35~45%를 차지한다.
- 좁은 복도에서도 카메라 충돌로 벽을 뚫지 않는다.
- 조준 중에는 목표와 총구 사이를 환경 소품이 가리지 않게 레벨을 배치한다.
- 전력 소켓은 8~12m 거리에서 형태가 읽히고, 3m 안에서 상호작용 문구가 나타난다.
- 보스 경기장은 카메라가 뒤로 물러날 공간과 좌우 회피 폭을 먼저 확보한 뒤 장식한다.

## 9. 캐릭터·적 통일 방법

### 채택 주인공: Striker14

- 원본: [Jumpsuit Low Poly Game Ready (Striker14)](https://sketchfab.com/3d-models/jumpsuit-low-poly-game-ready-striker14-da288adbddf949aa85962968732f0999) · DanlyVostok · CC BY 4.0
- 역할: 정전된 화물역에 투입된 시설 관리 기술자. 특수부대나 우주군으로 보이지 않아야 한다.
- 유지: 성인 인체 비율, 얇은 점프슈트 실루엣, 검정·차콜 기반, 모자와 마스크.
- 변경: 주황 발광선은 청록 전력 표시로 바꾸고, 안전 황색은 작은 식별 마킹에만 사용한다.
- 장착: 새 배낭을 모델링하지 않고 기존 산업용 전력함 소품을 골라 등뼈에 부착한다. 화면에서 전력 3칸이 세로로 읽히게 한다.
- 금지: 방탄판, 탄창 파우치, 큰 견갑, 군 계급장처럼 전투병으로 읽히는 장비 추가.
- 기술 상태: 시각 기준 채택, Unity Humanoid·조준·사격 리타게팅 검증 전. 검증을 통과해야 제작용 `approved`가 된다.

서로 다른 제작자의 모델을 같은 색으로 칠하는 것만으로는 통일되지 않는다. 아래 세 요소를 최소 두 개 이상 공유해야 채택한다.

- 같은 표면군: 무광 건메탈, 검은 고무, 안전 황색 마킹
- 같은 발광 언어: 플레이어 전력은 청록, 적 센서는 적색
- 같은 형태 반복: 사각 배터리 팩, 노출 케이블, 굵은 산업용 볼트
- 같은 노후도: 모서리 마모는 있으나 폐차 수준의 녹은 없음

주인공에게 전투병 장비를 덧붙이지 않는다. 보호복·공구 벨트·배터리 가방만으로 역할이 읽혀야 한다. 보스도 외계 병기가 아니라 같은 시설 보안 장비의 대형 버전으로 보이게 한다.

## 10. VFX·UI·사운드 연결

### VFX

- 기본 펄스: 짧은 청록 핵 + 옅은 흰색 꼬리, 0.25초 이내.
- 충전 펄스: 총의 3칸이 순서대로 켜지고 발사 순간만 밝아진다.
- 적 피격: 주황 불꽃과 금속 파편. 피나 보라색 마법 효과는 금지한다.
- 전력 흡수/주입: 월드 소켓과 총 사이를 이동하는 세 덩어리로 자원 수를 보여준다.
- 화면 흔들림과 번쩍임은 짧게 사용하고 조준을 방해하지 않는다.

### UI

- HUD는 산업 장비 계기판처럼 얇은 선, 사각 슬롯, 숫자 중심으로 만든다.
- 체력과 전력은 다른 형태를 쓴다: 체력은 가로 막대, 전력은 독립된 세 칸.
- 검은 반투명 패널과 흰 글자, 청록 정상, 황색 주의, 적색 실패만 사용한다.
- 화면 장식보다 월드 안의 조명·소켓·적 센서가 먼저 정보를 전달한다.

### 사운드

- 통전: 저주파 기계 시동 → 릴레이 클릭 → 형광등 점등 순서.
- 회수: 위 순서를 거꾸로 하되 피치를 낮춰 “되돌림”을 느끼게 한다.
- 적 공격 예고는 무기 소리보다 먼저 들려야 한다.
- 정전 구간은 무음이 아니라 빗물, 금속 팽창음, 먼 발전기 저음으로 채운다.

## 11. 기술 예산

| 항목 | 일반 대상 | 영웅 대상 |
|---|---:|---:|
| 텍스처 | 1K, 반복 재질 우선 | 주인공·보스만 2K |
| 삼각형 | 소품 1k~20k, 일반 적 80k 이하 목표 | 주인공 80k 이하, 보스 120k 이하 목표 |
| 재질 슬롯 | 소품 1~2개 | 주인공·보스 4개 이하 |
| 실시간 그림자 | 주요 조명 1개 중심 | 보스 예고등만 제한 추가 |
| LOD | 15m 이상 보이는 복잡한 메시 필수 | 일반 적·보스 필수 |

기준을 넘는 무료 모델은 “고품질”로 간주하지 않는다. 한 개뿐인 주인공은 예외를 검토할 수 있지만, Profiler에서 60fps를 확인하고 LOD 또는 메시 단순화 계획이 있어야 한다.

## 12. 에셋 승인 게이트

1. 원본 페이지에서 무료 가격, 제작자, 라이선스를 기록한다.
2. 별도 테스트 장면에서 1m 스케일, 피벗, 노멀, UV, 재질을 확인한다.
3. 주인공은 Humanoid Avatar와 기본 이동·조준 애니메이션을 확인한다.
4. 적은 NavMesh 이동 중 발 미끄러짐, 충돌체, 사망 포즈를 확인한다.
5. 환경·주인공·적·보스를 같은 조명 아래 한 화면에 놓는다.
6. 위 색상·재질 규칙을 적용한 뒤에도 어색하면 에셋을 교체한다.

주 환경 `ENV-01 Modern Industrial Pack`과 주인공 `CHR-01 Striker14`는 기획·시각 기준으로 채택했다. 아직 설치되지 않았으며, [에셋 가이드](BLACKOUT_AssetGuide.md)의 Unity 검증 게이트를 통과한 뒤에만 제작용 `approved`로 바뀐다. 나머지 외부 에셋은 후보 상태다.
