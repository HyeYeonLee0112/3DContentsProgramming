## 0. 한 줄 요약 & 선정 논리

고장난 우주 정거장. 구역마다 **중력 방향이 다르다.** 벽·천장을 걷고, 무중력 구간을
관성으로 헤엄치고, 그래플로 붙잡으며 적을 제압하는 TPS.

- 수업 커리큘럼 100% 커버
- 차별점이 **이동 자체** — 쿼터니언/transform 수학, 카메라 up 재정렬, `Physics.gravity` 조작.
  대부분 학생의 "평지에서 쏘는 슈터"와 확실히 다름
- **재미의 핵심이 게임필**: 이동 감각만 잘 뽑으면 짧아도 강한 인상 (소형 타이탄폴)

## 2. 픽션 & 톤

- 무대: 인공중력이 붕괴한 궤도 정거장 "NULL-G". 구역마다 중력 발생기 상태가 달라 방향/세기가 제각각.
- 플레이어: 정거장 복구 유닛. 코어까지 전진하며 중력 발생기를 재가동.
- 톤: 저채도 SF, 고요함. 창밖 우주(스카이박스)로 스케일감.

## 3. 코어 루프

```
구역 진입 → 현재 구역 중력 상태 파악(방향/무중력)
 → 벽걷기·그래플·무중력 이동으로 전진, 적 로봇 제압
 → 공간 퍼즐 1개(경로 확보: 패널 사격, 중력 스위치)
 → 중력 발생기 재가동 = 구역 클리어, 다음 구역
 → 코어 재가동 = 클리어  /  체력 0 = 마지막 체크포인트
```

## 4. 차별화 레이어 (핵심 시스템)

### 4.1 중력 시스템
- **전역 중력존**: 트리거 볼륨마다 `gravityDir`, `gravityScale`. 플레이어 진입 시 목표 중력 갱신
- 플레이어 "아래" 방향을 목표 중력으로 **부드럽게 회전**(Slerp), 카메라 up 동기 보간
- 무중력존: 중력 0 + 관성 이동(추진기 입력), 회전 자유

### 4.2 벽걷기 (transform 수학)
- 발밑 레이캐스트 표면 법선 = 새 "up". 표면 전환 시 캐릭터·카메라 재정렬
- 코너(볼록/오목) 처리: 법선 보간, 낙하 판정

### 4.3 그래플 훅 (물리)
- 조준점의 앵커 포인트에 훅 발사 → `ConfigurableJoint` 또는 스프링으로 당김
- 스윙 관성, 릴리스 시 속도 보존

### 4.4 공간 전투
- 적: 벽/천장에 붙은 터렛, 무중력 부유 드론, 자기중력 로봇
- 조준이 3D 전방향 → 크로스헤어 + 표적 리드 표시
