## 0. 한 줄 요약 & 선정 논리

강습팀 리더가 되어 아군 유닛 2기를 지휘하며 적 시설을 층별로 돌파하는 TPS.
직접 쏘는 것 + **아군에게 이동·집중사격·엄폐를 명령**하는 전술 레이어가 핵심.

- 수업 커리큘럼 100% 커버
- 대부분 학생은 **적 AI**만 만든다. BREACH는 **아군 AI + 엄폐 시스템**까지 → 프로그래밍 교수 기준 **AI 깊이가 가장 인상적인 차별점**
- 핸드크래프트 미션이라 완성도 관리가 쉬움 (절차적 밸런싱 부담 없음)

## 2. 픽션 & 톤

- 무대: 무인 경비 시스템이 장악한 연구 시설. 층마다 목표(터미널 해킹, 인질 구출, 코어 파괴).
- 플레이어: 3인 강습팀 리더. 아군 **ECHO / DELTA** 는 로봇 전투 유닛.
- 톤: 저채도 전술 SF. 침착하고 절제된 분위기.

## 3. 코어 루프

```
미션 브리핑 (목표·맵 개요)
 → 진입 → 방 단위 교전
      · 플레이어: 직접 사격 / 엄폐 / 수류탄
      · 아군: 명령(이동지점 / 집중사격 / 엄폐 / 대기) 수행, 자동 교전
 → 목표 지점 도달·수행 (해킹 = 방어전, 구출 = 호위)
 → 다음 구역 … → 미션 완료 (또는 팀 전멸 = 실패, 마지막 체크포인트)
```

## 4. 차별화 레이어 (핵심 시스템)

### 4.1 아군 AI (Behavior Tree / GOAP-lite)
- 상태: `Follow / MoveToOrder / Engage / TakeCover / Suppress / Downed`
- 자율 판단: 위협 감지 → 가장 가까운 유효 엄폐로 이동 → 사선 확보 시 교전
- 명령 오버라이드: 플레이어 지정 지점/타겟이 자율 판단보다 우선
- **다운·부활**: 아군 HP 0 = 다운, 플레이어가 접근해 리바이브(홀드), 방치 시 사망

### 4.2 엄폐 시스템
- 레벨에 **커버 포인트** 배치(낮은/높은 엄폐, 좌/우 코너), `NavMesh`와 연동
- 유닛(플레이어·아군·적)이 커버 포인트에 스냅 → 피격률 감소, 코너에서 사격 시 노출
- 커버 포인트 유효성: 위협 방향 대비 각도 계산

### 4.3 적 분대 AI
- 적도 커버 사용 + 서로 엄호(한 명 전진 시 나머지 제압 사격)
- 측면 기동: 플레이어가 오래 한 자리 = 우회 시도

### 4.4 명령 UI
- 커서 지정(이동/타겟) + 라디얼 메뉴(집중사격/엄폐/대기/집결)
- 아군 상태(HP·탄약·명령) 미니 패널

## 9. 스코프 & 리스크

| 리스크 | 대응 |
|---|---|
| 아군 AI + 적 AI + 커버가 이 3안 중 최난도 | 커버 포인트를 **수동 배치**(자동 생성 안 함)로 단순화. AI는 BT 라이브러리(무료) 활용 가능 |
| 아군이 답답하면 게임 전체가 답답 | 명령 즉응성 우선 튜닝. 자율 AI는 "적당히"만 |
| 레벨 디자인 시간 | 미션 3개, 재사용 모듈, 짧게(8분) |
| 스코프 초과 | MVP는 미션 3 + 목표 2 + 정예 1이면 성립 |
