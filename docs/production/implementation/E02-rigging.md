# E02 — Animation Rigging으로 총 손잡이와 손 맞추기

애니메이션을 바꾸면 왼손이 총에서 떨어질 수 있다. 기본 동작 위에 손의 목표 위치를 더해 보정하고 극단 조준에서의 한계를 확인한다.

선행: [T09](09-animation.md) · 연결: K18 · [전체 목록](README.md)

## 개념·책임·설정 계약

IK는 손 같은 끝점의 목표에서 팔 관절 자세를 계산하는 방식이다. [Two Bone IK](https://docs.unity3d.com/Packages/com.unity.animation.rigging@1.3/manual/constraints/TwoBoneIKConstraint.html)는 위팔·아래팔·손과 팔꿈치 방향 힌트를 사용한다.

| 대상 | 계약·소유 |
|---|---|
| Animator 모델 Root | RigBuilder, 기본 애니메이션 평가 |
| Rig 자식 | Rig 컴포넌트와 왼팔 Two Bone IK |
| Constraint Root/Mid/Tip | 실제 왼팔 위팔/아래팔/손 뼈 |
| Target·Hint | 왼손 손잡이 목표·팔꿈치 굽힘 방향 |
| Weight | 조준 상태에서 보정 비율; 사망·비조준 정책 명시 |

첫 버전은 설정으로만 실험한다. 새 보정 제어 파일을 만들면 입력은 IsAiming, 출력은 Rig.weight 한 값으로 제한하고 업데이트 시점을 명시한다.

## 먼저 생각하기·의사코드

왼손 Target이 다시 왼손의 자식이면 계산이 자기 결과를 따라가며 흔들리지 않는가?

```text
기본 Avatar·애니메이션 검증 → 외부 총 손잡이에 Target
팔꿈치 Hint → Weight 0/1 비교 → 조준 범위 끝과 사망 전환 검사
```

## 따라하기

1. T09 프리팹의 실험 Variant를 만든다. 현재 리그·임포트 상태와 패키지 호환 버전을 확인한다.
2. Animator Root에 RigBuilder, 자식에 Rig를 만들고 레이어를 연결한다.
3. 왼팔 Two Bone IK에 실제 뼈 세 개를 연결한다. 총 손잡이에 Target, 팔 바깥쪽에 Hint를 둔다.
4. Weight를 0→1로 움직이며 기존 자세와 보정 결과를 비교한다. 총은 오른손/무기 소켓의 관계를 유지하고 왼손 목표가 순환 참조하지 않게 한다.
5. 걷기·달리기·상하 조준 끝·급회전에서 팔꿈치 뒤집힘·손목 꺾임을 본다.
6. 사망·피격 전환에서 보정이 과도하게 남으면 Weight 정책과 Animator 평가 순서를 조절한다. 총의 실제 발사 방향 규칙은 T06에 남긴다.

## 검증·완료 기준

- [ ] Weight 0/1 차이와 목표·힌트의 역할을 설명한다.
- [ ] 극단 조준·이동·피격·사망의 관절 문제를 확인했다.
- [ ] 목표와 뼈 사이 순환 관계가 없다.
- [ ] 보정 전후 영상과 추가 CPU 비용을 기록했다.

## 선택과 한계

IK는 에셋 조합의 오차를 줄이지만 잘못된 Avatar나 완전히 다른 기본 자세를 자동 해결하지 않는다. 목표 위치와 Hint 유지비가 생긴다. 먼저 좋은 기본 조준 클립을 찾는 것이 더 단순한 대안일 수 있다.
