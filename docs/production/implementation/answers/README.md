# 참고 구현을 보는 순서

실습 문서의 멤버 계약과 TODO를 먼저 시도한 뒤 필요한 원리만 비교한다. 아래는 해당 단계의 작은 구현 단위다. 프로젝트 코드에 적용·컴파일·플레이 검증된 결과가 아니다.

- [입력·수평 이동·점프](01-input-movement.md): T01~T05의 콜백·조립·이동·점프·카메라. Gate·Controller·Config는 전체 파일, 다른 절은 표시된 메서드/호출부 단위다.
- [목표점·종료·피해](02-combat.md): T06~T08의 조준·발사·명중·피해·HUD·사망. IDamageable·HealthHud는 전체 파일, 나머지는 메서드/호출부 단위다.
- [전력 이전·기록 복사](03-power-checkpoint.md): T12·T21의 순수 규칙.

일부 메서드는 앞 단계의 구현을 교체한다. 합쳐서 같은 이름의 메서드를 두 개 만들지 않는다. 필드·using·namespace·Inspector는 각 실습의 계약을 먼저 작성한다. 나머지 태스크는 실습 절차와 의사코드를 바탕으로 직접 구현하고 현재 코드 리뷰를 통해 확인한다.
